# Contributing

Kilnmark is source-available under the Business Source License 1.1 ([LICENSE](LICENSE),
[ADR 0008](docs/adr/0008-licence.md)).

- **Contributor agreement first.** Before a contribution from anyone other than the copyright
  holder is accepted, its author signs a contributor licence agreement. It lets the work be
  licensed under the BSL now and under other licences later. Open an issue to ask for it.
- **Your own work only.** Contribute only code and content you wrote or have the right to give.
  No code, files, names or data from any employer's or customer's products.
- **Borrowed code is logged.** Code adapted from Apache-licensed Kettle 10.2 or earlier keeps its
  Apache header and is recorded in [docs/legal/provenance.md](docs/legal/provenance.md). Code
  from Kettle 10.3 or later (BSL) or from Apache Hop is not accepted.
- **Decisions are recorded.** Anything hard to reverse gets a decision record in
  [docs/adr](docs/adr).
- **Accessibility.** UI changes meet WCAG 2.2 AA ([ADR 0009](docs/adr/0009-accessibility.md)).
