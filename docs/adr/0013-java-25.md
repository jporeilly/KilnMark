# 0013 Java 25 LTS

Status: Accepted (24 October 2026). Supersedes the Java version in [0004](0004-java-quarkus-arrow.md).

## Decision

Kilnmark builds and runs on **Java 25**, the current long-term-support release. Gradle runs on it
too (`JAVA_HOME`), because Quarkus's build steps run inside Gradle. The server image is
`eclipse-temurin:25-jre`, and CI sets up JDK 25.

## Why

- **Apache DataSketches 9**, which the profiler is built on, requires Java 25. DataSketches 8 runs
  on Java 21 only with `--enable-preview`, which has no place in a product.
- The foreign memory API is final from Java 22, which is where Arrow and DataSketches are moving.
- A product starting now should start on the newest LTS. Java 25 is supported for years longer
  than 21.
- It was cheap to check: the whole build, its tests and the packaged server all ran on 25 with no
  code changes ([Arrow spike](../spikes/0001-arrow-row-sets.md)).

## Cost

Customers running Kilnmark outside a container need a Java 25 runtime. The container image
carries its own, so for most installs this is invisible.
