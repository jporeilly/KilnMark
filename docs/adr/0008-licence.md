# 0008 Licence model

Status: Open

## Options

1. **Proprietary**: all rights reserved; sold under commercial licence.
2. **Open core**: an Apache-licensed core with commercial AI and enterprise features.
3. **Source-available** (for example Business Source License): source visible, production use
   needs a commercial licence until a change date.

## Current position

Until decided, the repository is proprietary (see LICENSE). Contributions from anyone else need
a contributor agreement before they are accepted, so any of the three options stays possible.
