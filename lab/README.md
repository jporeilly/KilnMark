# Reference lab

A self-contained test estate for development and the regression suite. Public and synthetic
data only: never customer data, and nothing from a former employer's labs.

Planned in sprint 0 (plan task 4):

- A sample relational database (PostgreSQL) with a small CRM and billing schema
- An S3-compatible bucket (MinIO) of CSV, Parquet and JSON files
- A file share with documents for later PII discovery
- A generated dataset seeded with fake PII
